# Greenlight — 3-Minute Demo Script (functional trailer)

Target length: **2:30–2:55**. English narration. Record the live hosted app.

## Setup before recording

1. Open https://greenlight-cinema.vercel.app full screen (zoom ~110%).
2. Confirm `/api/health` shows `parallel_key_configured: true` and `gemini_key_configured: true`.
3. Use the prefilled sample pitch **Night Shift at the Arcology**.

## Shot list (wow beats)

| Time | Visual | Narration |
|------|--------|-----------|
| 0:00–0:12 | Brand soft-focus reveal + amber Aurora | “Greenlight — studio diligence for the greenlight meeting.” |
| 0:12–0:30 | Pitch panel (title, logline, mid budget) | “Producers paste a pitch and budget band. Gemini frames the research plan.” |
| 0:30–0:40 | Click **RUN GREENLIGHT** | “A multi-step agent kicks off on Google Cloud.” |
| 0:40–1:35 | Production board: comps → market → risks → **slate/IP** with live SpotlightCards | “Parallel Search runs for real — comps, market, risks, then slate and IP collisions. Evidence cards appear as each lane finishes.” |
| 1:35–2:20 | Decision Packet: recommendation + CountUp confidence + scorecard + Monday Memo | “You get a Decision Packet — scorecard, comp table, and a Monday Memo you can paste into Slack.” |
| 2:20–2:40 | Click **Copy memo**, scroll sources by lane | “Every claim is backed by Parallel sources, grouped by diligence lane.” |
| 2:40–2:55 | End on brand | “Greenlight — Parallel track, Agentic Cinema.” |

## Do / Don’t

- DO linger on live Parallel evidence cards and the slate/IP step.
- DO show CountUp confidence and Copy Monday Memo.
- DON’T pad with cinematic B-roll that hides the product.
- DON’T exceed 3 minutes.
