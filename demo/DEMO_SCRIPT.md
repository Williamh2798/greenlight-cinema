# Greenlight — 3-Minute Demo Script (functional trailer)

Target length: **2:30–2:55**. English narration. Record the live hosted app.

## Setup before recording

1. Open the hosted Greenlight URL in a clean browser window (full screen).
2. Confirm `/health` on the API shows `parallel_key_configured: true`.
3. Use the prefilled sample pitch **Night Shift at the Arcology** (or paste from `demo/sample-pitches.json`).

## Shot list

| Time | Visual | Narration |
|------|--------|-----------|
| 0:00–0:15 | Brand lockup + tagline | “Greenlight turns a film pitch into a cited go/no-go brief for producers.” |
| 0:15–0:35 | Fill pitch fields | “We start with title, logline, genre, budget, and comps.” |
| 0:35–0:50 | Click **RUN GREENLIGHT** | “A Gemini agent on Google Cloud kicks off a five-step diligence workflow.” |
| 0:50–1:40 | Production board steps lighting up | “Frame the pitch… Parallel Search for comps… market… then risk signals. Parallel is called at runtime via the official Search API — not mocked.” |
| 1:40–2:25 | Scroll recommendation + markdown brief + source links | “The brief returns a recommendation, confidence, risks, diligence questions, and clickable sources from Parallel.” |
| 2:25–2:50 | Briefly show repo README or API `/docs` | “Open source on GitHub. Stack: Gemini ADK, Vertex AI, Parallel Search, Cloud Run.” |
| 2:50–2:55 | End on brand | “Greenlight — Parallel track, Agentic Cinema.” |

## Do / Don’t

- DO show real step transitions and real source URLs.
- DO keep UI readable (zoom browser to 110% if needed).
- DON’T add unrelated cinematic B-roll that hides the product.
- DON’T exceed 3 minutes (judges only watch the first 3).
